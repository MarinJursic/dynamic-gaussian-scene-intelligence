# ESO Guesthouse capture derivatives

These files are web-delivery derivatives of the European Southern Observatory photograph **Guesthouse living room (gh-livingroom-pan)**, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`context-8k.jpg` is selected on GPUs that report an 8192-pixel texture limit or
higher. `context-webgl.jpg` is the 4096×2048 compatibility fallback. Both retain the
source photograph's complete 360°×180° equirectangular field of view.

The canonical source, attribution, and transformation notes are recorded in [`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md).

# Generated continuation fixture

`room-02-ai-continuation.jpg` is a bundled, model-generated 2:1
equirectangular panorama used by the offline doorway walkthrough.

- **Role:** a clearly labeled generated continuation beyond the observed ESO
  Guesthouse room.
- **Source reference:** the attributed ESO Guesthouse panorama documented in
  `THIRD_PARTY_NOTICES.md`.
- **Generation date:** 2026-07-26.
- **Transformation:** generated at 1774×887, then resized to 2048×1024 with
  Lanczos resampling and stored as a high-quality JPEG.
- **Boundary:** this is not observed geometry, a metric reconstruction, or a
  claim about the real building. It exists to demonstrate the gated
  generate-before-entry interaction when no completion provider is configured.

The prompt requested a photorealistic adjacent corridor/gallery matching the
reference room's warm pink walls, white trim, parquet floor, exposure, and
architectural era. It explicitly prohibited mirroring, collage panels, people,
logos, text, black regions, warped doors, and visible panorama seams.
